\paragraph{Problem 3.} Let $f, g : X \to Y$ be continuous maps, and let $Y$ be Hausdorff. Then the following set is closed:
\[W = \{ x \in X : f(x) = g(x) \}. \]

\begin{proof}
Consider the map $\psi : X \to Y \times Y$ given by $x \mapsto (f(x), g(x))$. With the product topology on $Y \times Y$, this map is continuous, as for any open sets $U_1, U_2 \subseteq Y$, we get \[\psi^{-1}(U_1 \times U_2) = f^{-1}(U_1) \cap g^{-1}(U_2),\] which is open. Since this is a base that generates the box topology on $Y \times Y$, we know that $\psi$ is continuous.

We can show that the set $D = \{(y, y) : y \in Y\}$ is closed in $Y \times Y$. Let $(y_1, y_2) \in D^C$, and since $Y$ is Hausdorff, find two disjoint open sets $U_1 \ni y_1$ and $U_2 \ni y_2$. Then, the set $U_1 \times U_2$ must be open in $Y \times Y$, and $D \cap (U_1 \times U_2) = \varnothing$ as the two sets are disjoint. Thus, we can write
\[
D^C = \bigcup_{(y_1, y_2) \in D^C} U_1(y_1,y_2) \times U_2(y_1,y_2).
\]
We have written $D^C$ as a union of open sets, so it must be open and $D$ must be closed. Finally, $W = \phi^{-1}(D)$, and since $\phi$ is continuous, $W$ must also be closed.
\end{proof}

If we take $f = g$ and $X = Y$, this shows that the set of fixed points of a continuous map on a Hausdorff space is closed.
